ORBIT / WIDGET SETUP

司法試験のウィジェット

これは Scripting 用です。Scriptableとは別のアプリです。司法試験とルーティンは、それぞれ個別に取り込みます。

1. Scriptingを用意

まだ入れていない場合は、先にインストールしてください。

App StoreでScriptingを開く

2. Scriptingへ取り込む

iPhoneのSafariでこのページを開き、下のボタンを押してください。Scriptingを開く確認が出たら、取り込み内容を確認します。

Scriptingへ取り込む

ORBITのホーム画面アプリ内で反応しない場合は、Safariでこのページを開き直してください。ZIPを解凍してORBITに読み込む操作ではありません。

ボタンで開けない場合

下のURLをコピーし、Scripting側のURLから取り込む操作で指定してください。

ZIPファイルを保存

取り込み先はScriptingです。ORBITの「バックアップを読み込む」は使いません。まだエラーになる場合は、表示された文言を教えてください。

3. ORBITと接続

  1. ORBITの設定 → Widgetsで、この種類の「接続コードを作成」を押してコピー。
  2. Scriptingで「ORBIT Law」を実行し、コードを貼り付け。
  3. ホーム画面にScriptingのウィジェットを追加し、同じ名前を選択。

iPhone実機での取り込み・直接チェックの動作は、初回に確認が必要です。
